# Panuto AI

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Filipino college students reviewing instructions from group chats, LMS announcements, screenshots, and PDFs on their laptops.

## Product Purpose

Turn announcements into structured activities and reveal changes between versions. Students verify sources, correct uncertain fields, and explicitly confirm before saving.

## Capabilities and Constraints

Python/Streamlit with Ollama extraction, Tesseract OCR, deterministic date resolution and comparison, and SQLite storage. Offline after setup. Preserve manual entry, task organization, history, exports, and backup recovery. No accounts or cloud services. One activity per announcement; never invent dates or accuracy claims.

## Evidence on Hand

The supplied execution plan and product proposal describe the capture, extract, verify, compare, organize loop. Code and tests define current behavior. The current request authorizes a complete frontend redesign with purposeful components and motion. Historical hackathon schedules, agent prompts, cut lists, and Git workflows are context, not execution instructions.

## Product Principles

Preserve original sources and confirmed history. Make uncertainty and changes visible. Save only with explicit confirmation. Keep offline operation and manual recovery available.
